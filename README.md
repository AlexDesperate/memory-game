# Memory Game

## Описание проекта
Игра на поиск пар одинаковых карточек. Написана на чистом JavaScript (Vanilla JS) без использования сторонних фреймворков и библиотек. Вся HTML-разметка генерируется динамически из скрипта.

## Функционал
- Динамическая генерация игрового поля на 16 карт (8 видов эмодзи).
- Случайное перемешивание карточек алгоритмом Фишера-Йетса при каждом перезапуске.
- Подсчет количества ходов и найденных пар.
- Сохранение Топ-10 лучших результатов в LocalStorage с сортировкой по эффективности.
- Адаптивный интерфейс и универсальные модальные окна с поддержкой закрытия по кнопке ESC и клику на оверлей.

## Инструкция для локального запуска
1. Склонируйте репозиторий или скачайте файлы проекта (`index.html`, `style.css`, `app.js`).
2. Убедитесь, что все три файла находятся в одной папке.
3. Откройте файл `index.html` в любом современном браузере (рекомендуется Google Chrome).
